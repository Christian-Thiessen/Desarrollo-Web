# Buscador de episodios de Rick and Morty

- **Autor:** Nombre Apellido
- **Asignatura:** Fundamentos de Desarrollo Web (Ingeniería en Informática)
- **Variante:** C (Episodios), último dígito de cédula: _

## Descripción

Página de una sola pantalla que busca episodios en la [API de Rick and Morty](https://rickandmortyapi.com/documentation) por nombre y por temporada (S01 a S05), y los muestra en tarjetas con el código del episodio, el nombre, la fecha de emisión y la cantidad de personajes. La última búsqueda se guarda en `localStorage` y se repite al recargar la página.

Tecnologías: HTML semántico, CSS (Grid, Flexbox, variables y diseño responsive) y JavaScript (fetch con async/await, DOM, localStorage).
